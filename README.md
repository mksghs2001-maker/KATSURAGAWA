# 戦国群雄録 ― 八ビットの天下

PC-8801時代の国取りシミュレーションに着想を得た、オリジナルのブラウザゲームです。「信長の野望」の移植・エミュレーターではありません。画像・音楽・プログラムなどの原作アセットは使用していません。

## 起動

Node.js 20 以降が必要です。外部パッケージのインストールは不要です。

```sh
cd /workspace/KATSURAGAWA
npm start
```

ブラウザで起動したサーバーのポート3000を開きます。ポートは `PORT` 環境変数で変更できます。

## 遊び方

1560年、尾張の織田家から開始。12か国すべてを支配すると勝利、領地をすべて失うと敗北です。

- 地図をクリックして領国を選択。キーボードではTab・Enterで選択可能。
- 1: 開墾、2: 徴兵、3: 調練、4: 出陣、5: 米売却、6: 米購入、7: 施し、8: 税率変更、9: 次の季節。
- 行動は毎季3回。各領地は季節ごとに税収と兵糧を得て、秋は石高に応じた収穫があります。兵の維持には兵糧が必要です。
- 出陣は隣接国へ。隣接自国のうち兵力が最大の国から攻めます。兵30以上、兵糧30が必要。士気と兵数、乱数が勝敗を左右します。
- 勝利時は兵を占領地へ移し、敗北時は兵を失います。敵は季節ごとに増兵し、手薄な織田領へ侵攻します。
- 税率60%は収入が増えますが、毎季士気が10低下します。
- 記録はブラウザのlocalStorageへの手動保存。自動保存・サーバー保存ではありません。同じオリジン・同じブラウザで読み込んでください。

地図は簡略図です。全国版、武将個別能力、外交、戦術合戦、原作互換のルールやセーブ形式は未実装です。現段階は中部・畿内12か国の試作版です。

## 検証

```sh
npm test
```

内政・合戦・季節・税・敵侵攻・勝敗・セーブデータ検証のテストを実行します。

## GitHub Pages

`main` へのプッシュで `.github/workflows/pages.yml` がテストと静的サイトのデプロイを実行します。GitHub の Settings → Pages → Build and deployment → Source は **GitHub Actions** に設定してください。

公開先: https://mksghs2001-maker.github.io/KATSURAGAWA/

Pages では Node サーバーは不要で、ゲームの4ファイルのみ配信します。
