# 漢鳴 ― 群雄の志（中原六城版）

三国時代を題材としたオリジナルの個人用ブラウザ戦略ゲーム。『三國志IV』の公開情報を参考に、武将への命令・継続内政・部隊編成・野戦と攻城を独自ルールで実装しています。原作の画像・音楽・文章・プログラムを流用していません。

## 起動・検証

Node.js 20以降。外部パッケージやビルドは不要です。

```sh
cd /workspace/KATSURAGAWA
npm start
# 別のターミナル
npm test
```

標準ポート3000、`PORT`で変更可能。ゲームの「取扱説明書」から簡易ガイド、画面下のリンクから詳しい説明書を開けます。全文は [manual.html](manual.html) にあります。

## 実装した範囲

- 六都市・二十武将、劉備の徐州・小沛から始める架空の194年シナリオ
- 月進行と武将ごとの行動、統率・武力・知力・政治、特技・忠誠
- 農業・商業・治水・技術の担当と予算、月次の成果・収支報告
- 税率、民心、米相場、秋の収穫、兵糧消費、水害、反乱
- 対象を選ぶ登用、褒美、赴任、捕虜の登用・解放
- 期限付き不可侵同盟、偵察、兵糧工作
- 徴兵、調練、兵・金・糧の街道輸送
- 主将・副将と兵数・三兵科を選ぶ出陣
- 両軍一部隊ずつのヘックス野戦、迎撃・籠城、攻城と城門、火計・撹乱・一騎討ち、天候、撤退・補給
- 敵の増兵・訓練・侵攻と戦場AI、六城統一・滅亡
- localStorageへの手動保存と、戦闘中を含む読み込み・状態検証
- PC・スマートフォン対応の操作画面とゲーム内取扱説明書

仕様・費用・戦闘手順・未実装の範囲は [取扱説明書](manual.html) を参照。試作ではなく全機能を再現した製品、という意味ではありません。全中国、複数部隊の大合戦、海戦、城内別マップ、兵器製造、史実イベント、武将寿命、相性、音楽などは未実装です。

## 配信

GitHub Actionsはmainへのプッシュ時にテスト後、次のファイルをPagesへ配信します。

`index.html`、`manual.html`、`style.css`、`app.js`、`game.js`、`artwork.png`

サーバーなしの静的ホスティングでも動作します。設定でPagesのソースをGitHub Actionsにしてください。

## 保存互換性

六城版はバージョン3、保存キーは`kanmei-save-v3`。十二都市版や戦国版の記録は別枠で、削除しませんが、この版には読み込めません。自動保存やサーバー保存はありません。

## 検証方針

`npm test`は実際のルールで、命令消費、資産保存、内政予算、外交期限、捕虜、野戦から攻城・城門破壊・占領、敵侵攻、防衛、勝敗、長期進行、保存データの整合性を確認します。ブラウザでの検証は別途行い、画面操作・合戦中の保存再開・説明書・モバイル幅を確認します。

## 参考資料と素材

[調査・設計メモ](docs/sangokushi-iv-research.md) に情報源と採用方針を記録しています。機種を限定せず、共通するゲーム構造を参考にしています。数値・計算式・文章は独自です。

`artwork.png`は本作向けに生成した地形画と三枚の肖像です。劉備・関羽・張飛以外は仮の肖像を共用しています。地形画は演出であり、都市の位置や河川が厳密に史実と一致する地図ではありません。
