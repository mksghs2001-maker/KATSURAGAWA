# 漢鳴 ― 群雄の志

三国時代を題材とした、個人向けのオリジナルブラウザ戦略ゲームの試作です。既存ゲームの移植ではなく、画像・音楽・文章・プログラムなどの原作素材は使用していません。

## 起動と検証

Node.js 20以降が必要です。外部パッケージやビルドは不要です。

```sh
cd /workspace/KATSURAGAWA
npm start
# 別のターミナルで
npm test
```

標準ポートは3000。`PORT`で変更できます。GitHub Pages向けには`index.html`、`style.css`、`app.js`、`game.js`、`artwork.png`を静的配信します。既存のActionsワークフローはmainへのプッシュ時にテスト・配信します。

## 遊び方

194年、徐州の劉備として開始。十二都市をすべて支配すると勝利、全都市を失うと敗北です。地図の都市をクリック、またはTabとEnterで選択します。毎季の命令は3回です。

- 開墾：金30。在城武将の最大政治に応じて農業が上昇。
- 徴兵：金40・兵糧20で兵30。調練：金20で士気15上昇。
- 武将登用：金40で在野武将を1人迎える。開始時は趙雲・魯粛・徐庶・太史慈が在野。
- 武将赴任：選択都市の武将一覧で最後の1人を別の自都市へ移動。
- 米購入：金40で兵糧60。施し：兵糧30で士気20上昇。
- 税率：40％と60％を切替。重税は収入が増える一方、毎季士気10低下。
- 出陣：隣接する敵都市が対象。隣接自都市のうち最多兵力の都市から、最大武力の武将が出陣。兵40以上・兵糧50が必要。兵力・指揮官の武力・士気・乱数で即時決着。
- 勝利時は一部の兵と指揮官が占領地へ移動。守将は在野になります。敗戦時は兵を失います。
- 次の季節：税収、兵糧消費、秋の収穫、敵の増兵・手薄な自都市への侵攻が発生。

記録はlocalStorageへの手動保存です。同じブラウザと同じオリジンで読み込んでください。旧戦国ゲームの保存とは別枠で、互換性はありません。

## 試作の範囲

十二都市・十七武将、内政、登用、赴任、簡易戦闘、敵AI、勝敗、保存を実装しています。都市配置・能力・勢力配置は独自の簡略モデルで、厳密な史実再現ではありません。武将の知力は表示のみで、計略は未実装です。外交、戦術マップ、顔画像、音楽、勢力選択、史実イベントは今後の拡張対象です。

## 画面素材

`artwork.png`は本作向けに生成した独自の地形画と三枚の武将肖像です。原作画像は使用していません。肖像は劉備・関羽・張飛を主に表す三種類で、他の武将は仮に主君の肖像を共用します。背景は雰囲気を表す地形画で、史実の地理と一致するものではありません。
